
# XRaySense

**Physics-Informed X-ray Signal Processing, Source Classification & Explainable AI**

## Overview

XRaySense is a scientific Python project investigating how physically meaningful features from public X-ray observations can support reproducible data analysis, signal processing, machine learning, and interpretable predictions.

The project uses public XMM-Newton data and emphasizes scientific validity, measurement uncertainty, and robust model evaluation.

## Research Questions

1. Which physical X-ray features are informative for source characterization?
2. Can machine-learning models distinguish independently labeled source classes without data leakage?
3. How can real X-ray light curves be analyzed to investigate variability and candidate periodic signals?

## Planned Methods

- X-ray catalogue quality control and feature extraction
- Statistical uncertainty analysis
- Supervised machine learning with grouped validation
- Time-series signal processing
- Anomaly detection and explainable AI
- Reproducible Python software and automated tests

## Data

Planned data source: 4XMM-DR14, XMM-Newton Survey Science Centre.
